# ClassClip

> 面向大学生的校园时间管理 Android 应用，将「课程表 · 待办事项 · 习惯打卡 · 时间规划」整合于一体，帮助学生把学习与生活安排得井井有条。

- 开发语言：**Java**
- 布局方式：**XML**
- 最低支持：**Android 7.0（API 24）**
- 数据存储：**SQLite 本地数据库**（完全离线，无需联网）

---

## 功能特性

### 1. 课程表

- **动态课程网格**：按星期 × 上课小节生成网格，课程块按起止小节纵向跨行，配色自动分配
- **周次自动推算**：设置开学日期后自动计算当前是第几周，顶部可切换周数
- **多课表并存**：支持创建多张课表（如单周/双周课表），随时切换
- **自定义上课时间**：可自由设置每节课时长、小课间/大课间时长、上午/下午/晚上各几节课，课程表网格同步变化
- **教务课表导入**：支持导入教务系统导出的课表文件（基于 Apache POI 解析）
- **非本周课程置灰**：非当前周的课程以灰阶显示，聚焦本周安排

### 2. 待办事项

- **三种视图**：周待办表 / 月待办表 / 全部视图，一键切换
- **月历视图**：整月网格展示，每天显示待办彩色标签，点击某天查看当天全部待办
- **优先级 + 四象限**：每条待办可设优先级（高/中/低）与四象限归属
- **分组展示**：未完成 / 已完成两组，可展开收起并统计数量
- **完整交互**：勾选完成、左滑删除或重置、点击卡片进入编辑

### 3. 习惯打卡

- **灵活频率**：支持「每天 / 指定周几 / 每周 N 次」三种目标模式
- **进度环**：顶部环形进度展示今日打卡完成情况
- **自定义分类**：分类支持新建、重命名、删除（删除分类会连带清理其下习惯）
- **连续天数**：自动统计连续坚持天数，本周格子直观展示打卡轨迹

### 4. 时间规划

- **待办时间轴**：按日期节点横向排列，每个节点一张卡片展示当天待办（最多 3 条，超出显示「+N」），点击进当天详情
- **四象限视图**：按「重要且紧急 / 重要不紧急 / 紧急不重要 / 不紧急不重要」四宫格分类，每格可点进明细
- **智能建议**：根据当日待办情况动态生成建议
- **数据复用**：全部数据来源于待办模块，与待办页实时同步

## 技术栈

| 类别 | 选型 |
|------|------|
| 语言 | Java |
| 布局 | XML（不使用 Compose） |
| 页面容器 | ViewPager2 + Fragment |
| 列表 | RecyclerView |
| 数据库 | 原生 SQLite（SQLiteOpenHelper） |
| 文件解析 | Apache POI（课表导入） |
| 导航 | BottomNavigationView + DrawerLayout |

## 项目结构

代码按功能分包，职责清晰：

```
com.example.classclip
├── common/      公共层：入口、数据库、通用控件、工具类
├── timetable/   课程表页（8 个类）
├── todo/        待办页（5 个类）
├── habit/       习惯页（4 个类）
└── plan/        时间规划页（2 个类）
```

资源（layout / drawable / anim）同样按页面分目录存放，通过 Gradle `res.srcDirs` 合并，引用名保持不变。

### 核心类说明

| 类 | 作用 |
|----|------|
| `MainActivity` | 应用入口，ViewPager2 承载四个页面 + 底部 Tab + 侧边抽屉 |
| `MainPagerAdapter` | ViewPager2 适配器，按位置返回四个 Fragment |
| `DBHelper` | SQLite 数据库封装，含 6 张表与逐级版本迁移 |
| `TimetableFragment` | 课程表网格动态生成、周次计算、课程编辑 |
| `TodoFragment` | 待办三视图切换、月历、左滑删除 |
| `HabitFragment` | 习惯列表分组、进度环、分类管理 |
| `PlanFragment` | 时间轴与四象限视图 |

## 数据说明

应用数据全部存储在本地 SQLite（`classclip.db`），包含 6 张表：

| 表名 | 用途 |
|------|------|
| `settings` | 配置项（开学日期、上课周数、当前课表等） |
| `timetables` | 多张课表 |
| `courses` | 课程数据（星期、起止小节、课名、教室、老师、颜色） |
| `time_schemes` / `scheme_times` | 上课时间方案与推导小节时间 |
| `todos` | 待办（含优先级、四象限字段） |
| `habits` / `habit_records` / `habit_categories` | 习惯、打卡记录、分类 |
